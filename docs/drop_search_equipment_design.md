# 装备系统设计 — 武器 + 补给品体系

## 一、设计目标

1. 建立具象化的**武器系统（per-player）+ 补给品系统（team-shared）**，提升模拟真实度和可观测性。
2. 武器分为近距离与远距离两类、T0~T3 四档，按队员维度独立持有，高低替换形成装备成长线。
3. 补给品（电池/医疗包）为团队共享资源，在战斗打盾/打血阶段消耗，消耗后直接回满对应属性。
4. 引入"舔包"机制：淘汰队伍的武器择优替换、补给品全盘接收，形成以战养战的滚雪球节奏。
5. 系统设计预留扩展空间，后续可加入投掷物、热盾、凤凰治疗包等新品类。

## 三、装备数据结构

### 3.1 单件武器

每把武器包含以下属性：

| 字段 | 类型 | 说明 |
|------|------|------|
| 类型 | 枚举：近距离 / 远距离 | 决定在哪个战斗环节使用 |
| 等级 | T0 / T1 / T2 / T3 | 数字越小越强 |
| 名称 | 文本 | 中文名，如"R-99 冲锋枪" |
| 英文名 | 文本 | 英文原名，如"R-99 SMG" |
| 弹药类型 | 文本 | 轻型 / 重型 / 能量 / 霰弹 / 狙击 / 特殊 / 弓箭 |
| 伤害倍率 | 小数 | 由 tier 唯一决定，T0=1.0 至 T3=0.55 |

### 3.2 队员装备

每个队员独立持有 **2 把武器**（1 近 + 1 远）：

| 装备槽 | 类型 | 初始值 | 说明 |
|--------|------|--------|------|
| 主武器（近） | 近距离武器 | 随机 T3 武器 | 战斗中决定伤害输出 |
| 副武器（远） | 远距离武器 | 随机 T3 武器 | 当前仅占位，战斗不生效 |

> 落地时从 T3 武器池中随机分配给每人，不同队员可能持有不同 T3 武器。

### 3.3 团队补给品

补给品为**团队共享**，不计个人归属：

| 补给品 | 用途 | 落地自带 | 上限 |
|--------|------|---------|------|
| 电池 | 战斗中打盾阶段消耗，护盾回满 | 2 个 | 无上限 |
| 医疗包 | 战斗中打血阶段消耗，HP 回满 | 2 个 | 无上限 |
| 手雷（预留） | 后续扩展 | — | — |
| 凤凰治疗包（预留） | 后续扩展 | — | — |
| 热盾（预留） | 后续扩展 | — | — |

## 四、资源点规则

### 4.1 资源点等级

每个资源点拥有固定数量的"搜索次数"（Token），每次搜索消耗 1 次并产出 1 件物品：

| 等级 | 数量 | Token 范围 | 颜色标识 | 定位 |
|------|------|-----------|---------|------|
| 高级 | 3 个 | 12 ~ 18 | 金色 | 核心战略点，高产 |
| 中级 | 7 个 | 7 ~ 11 | 紫色 | 常规发育点 |
| 低级 | 10 个 | 3 ~ 6 | 白色 | 边缘散点，低产 |

### 4.2 搜索条件

- 队伍处于资源点的有效半径范围内。
- 资源点剩余 Token > 0。

### 4.3 搜索节奏

| 场景 | 每轮消耗 | 说明 |
|------|---------|------|
| 单队伍独占 | 1 Token/轮 | 正常速度 |
| 多队伍同点 | 1 Token/轮（共享池） | Token 池被多队同时消耗，更快枯竭 |
| 城区地形 | +20% 搜索频率 | 城区物资密集，搜索更快 |

---

## 五、搜索产出规则

### 5.1 产出类型概率

每消耗 1 个 Token，按以下概率产出：

| 产出类型 | 基础概率 |
|---------|---------|
| 近距离武器 | 35% |
| 远距离武器 | 20% |
| 电池 | 25% |
| 医疗包 | 20% |

### 5.2 武器等级权重

当确定产出武器（近或远）后，按以下权重确定具体等级：

| Tier | 基础权重 | 高级资源点修正 | 低级资源点修正 |
|------|---------|--------------|--------------|
| T0 | 5% | → 12% | → 2% |
| T1 | 15% | → 25% | → 8% |
| T2 | 30% | → 33% | → 25% |
| T3 | 50% | → 30% | → 65% |

> 确定 tier 后，从该 tier 的对应类型武器池中再随机选一把具体武器。

## 六、武器替换规则

### 6.1 搜索获得武器时

1. 确定产出武器类型（近/远）
2. 从队伍中随机选一名队员作为获得者
3. 比较该队员当前**同类型**武器的等级：
   - **新武器等级更高（数字更小）** → 替换，装备升级
   - **新武器等级相同或更低** → 丢弃，不替换
4. 替换/丢弃时输出相应提示信息

### 6.2 舔包获得武器时

见第八章舔包规则。

---

## 七、补给品消耗规则

### 7.1 消耗时机

在战斗中，队员进入特定状态时触发消耗：

| 队员状态 | 消耗品 | 效果 | 条件 |
|---------|--------|------|------|
| 打盾（回甲） | 1 电池 | 护盾回满 | 队伍电池 > 0 |
| 打血（回血） | 1 医疗包 | HP 回满至 100 | 队伍医疗包 > 0 |

### 7.2 无补给品时的处理

- 若对应补给品数量为 0，队员**无法执行该状态**。
- 队员自动转入待机或掩体躲避状态。
- 输出提示信息（如"XX 想打电池但没有电池了！"）。

---

## 八、舔包规则（淘汰掠夺）

### 8.1 触发条件

当一支队伍在战斗中被全员淘汰时，由**最后一个对该队伍造成伤害的队伍**触发舔包事件。

### 8.2 规则 a — 补给品全盘接收

- 胜方获得败方的全部电池和医疗包（数量直接累加）。
- 败方补给品清零。

### 8.3 规则 b — 武器择优替换

胜方每个队员遍历败方每个队员的武器：

- 如果败方某队员的近距离武器等级 > 我方当前近距离武器 → 替换
- 如果败方某队员的远距离武器等级 > 我方当前远距离武器 → 替换
- 每个队员独立比较，可从不同败方队员处获得不同武器
- 舔包完成后败方队员武器清空

## 九、伤害计算规则

### 9.1 伤害公式

```
实际伤害 = 基础伤害 × 近距离武器倍率 × 瞄准修正 × 地形修正 × 爆头修正
```

### 9.2 参数说明

| 参数 | 取值 | 来源 |
|------|------|------|
| 基础伤害 | 固定 20 | 每发子弹固定值 |
| 近距离武器倍率 | T0=1.0 / T1=0.85 / T2=0.70 / T3=0.55 | 攻击方队员的主武器等级 |
| 瞄准修正 | aim属性 ÷ 50 | 攻击方队伍瞄准能力 |
| 地形修正 | 1.15 / 1.0 / 0.85 | 攻击方与防御方地形优劣势对比 |
| 爆头修正 | 1.75（爆头）/ 1.0（未爆头） | 概率触发，受瞄准能力影响 |

## 十、装备状态流转

```
开局降落
  │  每人：随机 T3 近战武器 + 随机 T3 远程武器
  │  团队：电池×2 + 医疗包×2
  ▼
搜索资源 ──── 消耗 1 Token，随机产出 1 件物品
  │              ├─ 武器：同类型比较等级，更高则替换
  │              └─ 补给品：存入团队池
  │                      │
  │                      ▼
  │                 资源点枯竭（Token 归零）
  │                      │
  ▼                      ▼
转移 / 交战
  │  伤害 = 基础伤害 × 近战武器倍率 × 其他修正
  │  打盾 → 消耗 1 电池 → 护盾回满
  │  打血 → 消耗 1 医疗包 → HP 回满
  ▼
战斗结束（敌方淘汰）
  │  最后造成伤害的队伍触发舔包：
  │  ① 补给品全收  ② 武器逐人择优替换
  ▼
循环 → 继续搜索 / 交战 → 直至决赛
```

## 十一、扩展预留

| 扩展方向 | 预留设计 | 说明 |
|---------|---------|------|
| 投掷物 | 武器类型可扩展 `throwable` | 破片手雷、电弧星、铝热剂等 |
| 新补给品 | 补给品字典可增加条目 | 凤凰治疗包（同时回满盾+血）、热盾（毒圈减伤） |
| 远距离武器启用 | 数据结构已就位 | 增加距离判断分支，远距离武器在不同射程发挥不同倍率 |
| 武器配件 | 武器结构可加 `attachments` 字段 | 瞄具（+命中率）、弹匣（+子弹数）、枪托（+稳定性） |
| 黄金武器 | T0 变种概念 | 附带满配配件的究极武器 |
| 空投补给 | 动态事件扩展 | 中后期空投专属 T0 武器或稀有补给品 |
